# switch-a-model

Use when a bot's model or API key needs to change — and it has to happen on the box, not from the phone or tablet app.

The procedure is in [SKILL.md](SKILL.md). The cost rule and the 402 story behind it are in [references/cost.md](references/cost.md).

Assumes: reach to the box, by a shell or by the app running on the box's own desktop.
