# restart-a-box

Use when an OpenMausBot box is broken or behaving oddly — the service is down, the model list is empty, Chrome won't start, or the tunnel stopped answering after a reboot.

The procedure is in [SKILL.md](SKILL.md). The fault table, with the exact text to look for, is in [references/faults.md](references/faults.md).

Assumes: OpenMausBot installed as a user-level systemd unit, and a person who may only be able to paste commands.
